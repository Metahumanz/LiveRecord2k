# Orin 合并工作盘选择修复

2026-10-04，Orin 安装版本 0.9.3。故障场次为真栗 `883263_真栗_20261003_200838`，包含 21 个源分段，合并目标约 13745.545 秒。源规格包含 1080p、1440p 和 4K，必须规范化后合并。

## 原因

非 POSIX 输出盘的合并链路强制在 `/tmp` 保存中间视频与成片。规范化峰值预计 35.77 GiB，加 2 GiB 保护空间后需要 37.77 GiB；本机仅剩 32.83 GiB。因此合并在空间预检阶段失败，未开始编码。输出 CIFS 盘 `/mnt/zzzz` 仍有约 1.6 TiB，但合并没有像 Scene 导出一样回退到输出盘。确定性的空间不足还被自动重试三次，并覆盖了进度区的具体原因。

## 修复

- 保留本机工作盘优先策略；空间不足且输出盘为另一文件系统时，在输出目录建立独立 `.br2k-merge-media-*` 工作目录。两边都不足、同卷或无关读写错误不会绕过保护。
- 规范化与最终封装始终按实际工作盘检查空间。无损拼接需要回退规范化时，重新检查更大的峰值，必要时重新选择工作盘。
- 成片仍通过媒体与时间轴检查后原子发布；失败保留源录像，结束清理本任务工作目录。发布失败的诊断改为“临时成片”，兼容本机与输出盘位置。
- `BR2K_DISK_SPACE_INSUFFICIENT` 和 `ENOSPC` 不再进入自动重试；保留具体失败原因供释放空间后手动重试。
