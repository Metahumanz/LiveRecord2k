## 修复

- 表情地址通过可信 CDN 检查后统一为 HTTPS；历史 HTTP 事件、协议相对地址和旧资源映射兼容。远程表情使用同一归一化 key，避免重复图片及预览资源 ID 不一致。
- Scene 和兼容 ASS 共用归一化快照映射。防止 CUDA 出图后，ASS 参考图仍把表情当成原文字，触发错误的画面门禁结果。
- Image 表情新增 contain 属性。CUDA 与 FFmpeg 在原字格内等比缩放并透明居中，原字格宽度、文字排版和字体保持；宽图不会被挤成正方形。
- Scene 构建日志增加图片表情快照匹配数；缺少快照时明确提示对应原文回退。旧录像没有保存图片的情况仍能导出文字，不凭空补图。
